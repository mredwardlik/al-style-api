# API Al-Style

Справка по дилерскому API портала Al-Style, по которой написан клиент. Перенесена
из исходного документа `API Al-Style.docx` (2019), личный токен из неё убран.

API позволяет синхронизировать сайт с порталом Al-Style: получать актуальную
номенклатуру товаров с ценами, остатками, описанием и фото.

- Технология: RESTful API, запросы методом `GET`, ответ в формате JSON.
- Адрес API: `https://order.al-style.kz/api`
- Для каждого запроса нужен личный ключ `access-token`, его выдаёт Al-Style.
- Техподдержка: admin@al-style.kz

> По состоянию на 2026 год домен `order.al-style.kz` не существует. Если API
> переехал, новый адрес задаётся параметром `--url` или переменной `ALSTYLE_URL`.

## `/date`: актуальность данных

| Параметр       | Описание                        |
| -------------- | ------------------------------- |
| `access-token` | Ваш личный авторизационный ключ |

```json
"2017-12-11 23:16:00"
```

## `/categories`: список категорий

| Параметр       | Описание                        | По умолчанию |
| -------------- | ------------------------------- | ------------ |
| `access-token` | Ваш личный авторизационный ключ |              |
| `id`           | ID категории                    | все          |

Параметры ответа:

| Параметр   | Описание                              |
| ---------- | ------------------------------------- |
| `id`       | ID категории                          |
| `name`     | Наименование                          |
| `left`     | Свойство left по методу Nested Sets   |
| `right`    | Свойство right по методу Nested Sets  |
| `level`    | Глубина вложенности                   |
| `elements` | Количество товаров                    |

```json
[
  {"id": 3633, "name": "Мобильные телефоны и аксессуары", "left": 1, "right": 22, "level": 1, "elements": 0},
  {"id": 3638, "name": "Мобильные телефоны", "left": 2, "right": 3, "level": 2, "elements": 25}
]
```

## `/elements`: список товаров

| Параметр            | Описание                                                        | По умолчанию |
| ------------------- | --------------------------------------------------------------- | ------------ |
| `access-token`      | Ваш личный авторизационный ключ                                 |              |
| `category`          | ID категории. Можно указать несколько через запятую             | все          |
| `limit`             | Количество выдаваемых элементов (не больше 100)                 | 100          |
| `offset`            | Отступ выдаваемых элементов                                     | 0            |
| `additional_fields` | Дополнительные поля через запятую (список ниже)                 |              |

Дополнительные поля: `description` (описание товара), `brand` (бренд),
`weight` (вес), `warranty` (гарантия), `images` (изображения), `url` (ссылка
на сайте al-style.kz), `model` (модель), `barcode` (штрихкод).

Параметры ответа:

| Параметр    | Описание            |
| ----------- | ------------------- |
| `article`   | Артикул             |
| `name`      | Наименование        |
| `full_name` | Полное наименование |
| `category`  | ID категории        |
| `sort`      | Сортировка          |
| `price1`    | Цена дилерская      |
| `price2`    | Цена розничная      |
| `quantity`  | Остаток на складе   |
| `isnew`     | Новинка             |
| `ishit`     | Хит продаж          |
| `ispromo`   | Промо               |

```json
[
  {
    "article": 20908,
    "name": "Колонки Mi Bluetooth Speaker Square Box Чёрный",
    "full_name": "Колонки, Xiaomi, Mi Bluetooth Speaker Square Box FXR4037CN/FXR4043GL, Портативные, Bluetooth V4,0, Порт USB Type-C, RMS 5W, Время воспроизведения до 10 часов, Размер: 154.5x62x25.3 мм., Чёрный",
    "category": 3472,
    "sort": 0,
    "price1": 8434,
    "price2": 11490,
    "quantity": 0,
    "isnew": 1,
    "ishit": 0,
    "ispromo": 0
  },
  {
    "article": 20932,
    "name": "Колонки Mi Bluetooth Speaker Square Box II Белый",
    "full_name": "Колонки, Xiaomi, Mi Bluetooth Speaker Square Box II FXR4053CN, Портативные, Bluetooth V4,0, Порт USB Type-C, RMS 5W, Время воспроизведения до 10 часов, Размер: 154.5x62x25.3 мм., Белый",
    "category": 3472,
    "sort": 0,
    "price1": 10120,
    "price2": 13490,
    "quantity": ">50",
    "isnew": 0,
    "ishit": 0,
    "ispromo": 0
  }
]
```

Остаток `quantity` бывает числом или строкой вида `">50"`.

## `/element-info`: информация по товару

| Параметр            | Описание                                                  |
| ------------------- | --------------------------------------------------------- |
| `access-token`      | Ваш личный авторизационный ключ                           |
| `article`           | Артикул товара. Можно указать несколько через запятую     |
| `additional_fields` | Дополнительные поля через запятую (список ниже)           |

Дополнительные поля: те же, что у `/elements`, и ещё `detailtext` (детальное
описание товара) и `properties` (свойства товара).

Ответ такой же, как у `/elements`.

## `/images`: изображения товара

| Параметр       | Описание                                              | По умолчанию |
| -------------- | ----------------------------------------------------- | ------------ |
| `access-token` | Ваш личный авторизационный ключ                       |              |
| `article`      | Артикул товара. Можно указать несколько через запятую |              |
| `thumbs`       | Получать миниатюры: `1` или `0`                        | `0`          |

```json
[
  "http://img.al-style.kz/00024_1.jpg",
  "http://img.al-style.kz/00024_2.jpg",
  "http://img.al-style.kz/00024_3.jpg"
]
```

Для нескольких артикулов ответ приходит словарём `{"артикул": [ссылки]}`.

## `/quantity`: остатки товара

| Параметр       | Описание                                              |
| -------------- | ----------------------------------------------------- |
| `access-token` | Ваш личный авторизационный ключ                       |
| `article`      | Артикул товара. Можно указать несколько через запятую |

```json
10
```
